# Statut GUI (SE41), programme SAPMZRET_ART

Statut `MAIN` (statut d'écran) :
- Barre d'outils standard : Sauvegarder = `SAVE` (Ctrl+S), Retour = `BACK` (F3), Quitter = `EXIT` (Shift+F3), Annuler = `CANC` (F12), Entrée = `ENTER`.
- Pour les écrans 0100 et 0200, le même statut convient (sur 0100, Sauvegarder est ignoré).

Titre `T_MAIN` : « &1 » (le programme fournit « Créer article » ou « Modifier article X »).

Dans SE41, activez bien les touches de fonction F3 / Shift+F3 / F12 / Ctrl+S sur les boutons correspondants : c'est ce que `key:F3`, `key:Ctrl+S` du scénario envoient.
